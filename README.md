# 🐾 Pipo2doo

### Little tasks. Shared moments. Together.

Pipo2doo is a cute Android app for couples who want to organize everyday life, share photos, and support each other. Plan your day, celebrate small wins, and send your partner a little encouragement—all in one cozy space.

## 📱 Install on your phone

1. Open the download link on your Android phone.
2. Download **Pipo2doo-v1.1.0.apk**.
3. Open the downloaded file.
4. If Android asks, allow your browser or file manager to **install unknown apps**, then return to the installer. Wording varies by phone.
5. Tap **Install**, then **Open**.
6. Allow notifications when prompted if you want reminders and partner alerts.

Only install APKs from a source you trust. You can turn the “install unknown apps” permission off again afterward.

## 💕 Get started together

1. Create an account or sign in on each phone. **Use a separate account for each person.**
2. Open **Us** and use the partner pairing option. Follow the pairing instructions shown in the app.
3. Set your display name and avatar. Enable profile sharing on both accounts if you want your partner to see them.
4. Create a shared task or upload a Locket photo to check that both phones see the update.
5. Open **Us → Notifications** to review partner alerts and choose your preferred sound.

Internet access is needed for account access, shared updates, photo uploads, and push notifications. Android notification permissions and phone settings also affect alerts.

## 🔄 Updating the app

Download the newer release's APK and install it over the existing app. Normal updates must use the same application ID and signing key, with a higher internal version code.

If Android says the app cannot be installed, it may be a signing mismatch—for example, updating an Android Studio debug build with a release build. **Do not uninstall immediately:** uninstalling can remove local data. Record the error and check your backup or sync status first.

GitHub publishing does not automatically update an installed app. Download and install each update unless an in-app updater is added in a future version.

## 🛠️ Quick troubleshooting

**A partner's photo or avatar is missing**

- Check that both accounts are paired with each other and connected to the internet.
- For avatars, check profile sharing on both accounts.
- Keep the app open briefly while it refreshes. Retry an image if a retry option appears.

**Notifications are missing or silent**

- Check Pipo2doo's notification settings and Android's app notification settings.
- Check your selected sound, notification volume, and Do Not Disturb settings.
- Open the app after installation and sign in before testing partner alerts.
- Some phones restrict background activity; check those settings if alerts arrive late.

**Something still does not work**

[Report a problem](https://github.com/krispi319/Visual-Pinout-Studio/issues)

Include the app version, phone model, Android version, steps to reproduce, and expected versus actual behavior. Screenshots help, but remove private messages, personal information, pairing codes, and credentials first.

## 🧩 Built with

- **Kotlin and Jetpack Compose** for the Android app.
- **Supabase** for accounts, shared data, photo storage, and backend functions.
- **Firebase Cloud Messaging** for Android push delivery.

Supabase provides the shared backend; Firebase is used for push notifications. Notification delivery depends on network connectivity, device settings, and platform services.
