## Pipo2doo v1.4.7 · build 158

- **Bulk task-time editing:** change a fixed time such as 7:30 PM → 7:29 PM using **All open** to update linked unfinished occurrences and the template for future copies. **From here** updates the selected date onward.
- Already corrected one occurrence? Select **All open** and Save without changing other shared fields to reapply its current title and time to the unfinished series.
- Completed/cancelled history and unrelated tasks with the same name are retained. Time uses the selected app clock; other viewers see the corresponding local time.
- **Chat bubbles fit their content:** short messages and emoji use compact bubbles; longer messages wrap up to the existing maximum width. Replies, photos, reactions and delivery labels remain available.
- Server generation checks historical dates in the updated series timezone to prevent duplicate dates after a clock change.

Other page layouts and task permissions are retained. Dates, repeat rules, personal reminders/private notes, and switching between Anytime/fixed time continue to use **This task**.

### Update

Install **Pipo2doo-v1.4.7.apk** over the existing app; do not uninstall. Both partners should update. The `.apk.sha256` file is an optional integrity checksum.
