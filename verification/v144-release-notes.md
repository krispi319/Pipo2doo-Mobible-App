## Pipo2doo v1.4.4 · build 155

- Edit recurring tasks with **This task**, **From here**, or **All open**. Sync title, assignee, list and tags across linked unfinished occurrences, including tasks already generated and planned.
- Already corrected a title on one occurrence? Choose **All open** and save to copy it to the unfinished series.
- Delete one occurrence, future occurrences, or the entire unfinished series. Series deletion stops future repeats and keeps completed history.
- Compact task editor with the title first, small scope buttons, avatar assignment and optional private-note detail. Clearer red Delete action with the affected task count.
- Safer shared-series changes: conflicts fail together and remain available to retry.

The existing Lists page, Today layout, full Create task form and assignee-based notification rules are retained.

Dates, times, repeat settings, reminders and private notes are edited using **This task**. Series membership uses saved recurrence links; unrelated tasks with the same name stay separate.

### Install or update

Download **Pipo2doo-v1.4.4.apk** and install it over the existing app. No uninstall is needed. Android may ask you to confirm installation.

The `.apk.sha256` file is an optional integrity checksum, not an installer.
