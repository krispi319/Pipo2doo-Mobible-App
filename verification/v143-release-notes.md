## What's improved

- Task notifications follow the assignee: user 1 only, user 2 only, or both for Together. Reassignment cancels obsolete queued alerts; shared editing stays available to both partners.
- Profile avatars replace long names inside the personal assignment circles. The due-time pill fits its text, with the existing layout preserved.
- Opening chat clears the existing unread badge. New messages count again; Seen receipts still reflect visible messages.
- Optional online status in **Us > Chat visibility**. Default is Invisible.
- Clear saving, success and retry feedback for task detail changes, with failed drafts retained.
- Smoother in-app updates: **Update now** downloads, verifies and continues to Android's installer. Android still asks for installation confirmation.

## Install / update

Download **Pipo2doo-v1.4.3.apk**, or use the app's update control. Install over the existing app to keep your account and data. Do not uninstall first. Update both partners' phones to get all client fixes.

The `.apk.sha256` file is an optional checksum, not an installer.

Offline phones receive reassignment changes after reconnecting. Phone notification permissions, personal settings, quiet hours and Android battery restrictions still apply.

Version: **1.4.3**, Android version code **153**. Automated verification is recorded in `verification/v143.md`; physical two-phone delivery remains a manual acceptance check.
