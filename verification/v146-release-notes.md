## Pipo2doo v1.4.6 · build 157

- Fix blocked task saves when date, time, repeat, reminder or private-note changes are made under **From here** or **All open**. A confirmation now offers **Save this task**; **Keep editing** retains your draft and selected scope.
- Failed saves keep the task editor open for retry. A confirmed one-task save leaves other occurrences unchanged.
- Fix a false series-edit rejection when an existing private note contains leading or trailing whitespace. Title, assignee, list and tag changes still apply to the selected unfinished series scope.

Existing layouts, completed/cancelled history, shared permissions and assignee-based notification rules are retained. Scheduling and private-note changes continue to apply to one occurrence.

### Update

Install **Pipo2doo-v1.4.6.apk** over your existing app. Do not uninstall. Both partners can update using the same APK. The `.apk.sha256` file is an optional checksum.
